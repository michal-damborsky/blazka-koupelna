# Blažka — rekonstrukce koupelny a WC (3D vizualizace)

Interaktivní 3D náhled koupelny (166×164 cm) a WC (120×86 cm) postavený v Three.js.
Spustíš jednoduše otevřením `index.html` (resp. `koupelna-3d.html`) v prohlížeči
nebo přes URL GitHub Pages.

## Možnosti
- otáčení / přibližování / posun kamerou (OrbitControls)
- přepínání pohledů: půdorys, koupelna, WC
- nahrání vlastní textury dlažby a obkladu
- nastavení rozměru dlaždice, šířky a barvy spáry
- nastavení posunu (vazby) a směru pokládky (0° / 45° / 90°)
- úprava rozměrů obou místností a výšky stropu

## Aktualizace
Stačí změnit `koupelna-3d.html`, commitnout a pushnout — GitHub Pages
se přerolne sám během chvíle.
